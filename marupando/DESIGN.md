# DESIGN.md — まるぱん堂

## 1. コンセプト

「まるぱん堂」は、京都・三条河原町で創業170年（安政元年創業）のあんぱん専門の老舗。
代々の蔵で受け継いだ酒種（さかだね）と、丹波大納言小豆の自家炊きあんだけで、あんぱんを焼き続けている。

- 店名：まるぱん堂
- 場所：京都市中京区 三条河原町（三条大橋の西詰めから徒歩2分）
- 創業：安政元年／創業170年
- こだわり：丹波大納言小豆の自家炊きあん／蔵付き酒種の生地／焼き型は初代からの銅型
- 客層：地元の常連（お茶席・法事の御用）、観光のお客さま、贈答・引き出物の注文

## 2. トーン＆マナー（美学の指針）

Claude Cookbook の「美学プロンプト」の考え方（＝色・余白・階層・動きを先に言葉で決めてから作る）を適用する。

老舗だが古臭くしない。京都の町家の「白い漆喰壁 × 一本の墨線」を、余白と細い罫線で表す。

- ベースは白（#ffffff＝真っ白）。紙のような清潔感、余白を大きく。
- 文字は大きめ。本文 18px、見出しは 40〜68px。年配のお客さまも読める。
- アクセントは大納言小豆の色 #7a2733（あずき色）と、焼き色の #c99441（きつね色）の2色だけ。
- 縦の細い罫線と「壱・弐・参」の漢数字で、老舗の落ち着きを出す。
- 角丸は控えめ（14px）。影は薄く1段階だけ。
- 動きは「ふわっと1回」。派手なアニメは使わない。

### カラートークン

| 名前 | 値 | 日常語 |
|---|---|---|
| --bg | #ffffff | 背景の白 |
| --ink | #1b1917 | 文字の濃い墨色 |
| --azuki | #7a2733 | 小豆色（差し色） |
| --kitsune | #c99441 | 焼き色の黄土色 |
| --line | #e7e1d9 | 薄い区切り線 |

暗い配色のときはこの5色を暗い側に入れ替える（背景 #15120f、文字 #f4efe7）。

## 4. 必ず入れる機能

- 機能①：サイト内検索。入力するとページ全体を走査し、一致した語を黄色くハイライトし、
  一致しない品書き・年表・FAQ項目を隠して絞り込む。件数を表示。Escで解除。
- 機能②以降（おっ、すごい！枠）
  - スクロールでふわっと出るアニメーション
  - 明るい／暗い配色の切替（選択は端末に保存）
  - よくある質問の開閉
  - お気に入り保存（★を押すと端末に保存され、次回も残る）
  - お問い合わせフォーム（送信すると管理画面の受信箱に届く想定）

## 5. 表と裏のつながり

ホームページのフォーム送信内容は、ブラウザの保存領域（localStorage）に書き込まれ、
同じブラウザで管理画面を開くと受信箱に新着として並ぶ。実際のメール送信は行わない（モック）。

保存キーは `marupando.v1.` で始まる名前に統一する。

| キー名 | 中身 |
|---|---|
| marupando.v1.inquiries | お問い合わせ・ご注文の一覧 |
| marupando.v1.approvals | 承認ゲートの案件 |
| marupando.v1.products | 品書きと在庫 |
| marupando.v1.activity | 操作の記録 |
| marupando.v1.settings | しきい値などの設定 |
| marupando.v1.favorites | お客さまのお気に入り（表側） |
| marupando.v1.theme | 明るい／暗いの選択 |
| marupando.v1.seq | 受付番号の連番 |

## 6. 管理画面の仕様（最小で動く版）

- タブ5つ：ダッシュボード／受信箱／承認ゲート／品書き・在庫／分析・設定
- 問い合わせは100点満点で自動採点し、3段階に振り分ける
  - 75点以上：自動でOK（自動返信の下書きまで用意）
  - 45〜74点：人が確認
  - 44点以下：却下（いたずら・業者営業など）
- 採点の内訳：内容の具体性30／連絡先の確からしさ20／ご注文見込み額20／迷惑ワードの有無15／お得意様か15
- 大事な操作（返信送信・値引き・大口受注）は「番頭→女将」の2段階の承認ゲートを通す
- 確認はブラウザ標準の confirm を使わず、自前のモーダルを出す
- サンプルデータは問い合わせ12件・承認案件5件・品書き6件
- 各タブに「この画面でAIに頼むと良いこと」のヒントを添える
