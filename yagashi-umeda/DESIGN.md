# 夜菓子 YAGASHI ― 大阪梅田・大人のためのTikTokスイーツバー

## 1. コンセプト

大阪梅田でいちばんTikTokがバズっている、という設定の「大人かっこいい」
スイーツ専門店。これまでの2軒(BAKEBAKE=変化するスイーツ、
KOTEKOTE CAFE=コテコテな純喫茶)とは方向性を明確に変える。
軸は「甘いものを、夜のバーの所作で出す」こと。

梅田はオフィス街・高層ビル・夜景・バー文化の街。10代向けの
「映えるパステルスイーツ」ではなく、仕事帰りの大人がバーカウンターで
一杯やる感覚でデザートを楽しむ、という新しいカテゴリを提案する。
造語「夜菓子(よるがし)」は「夜カフェ」からの連想で、
"甘いものは夜に、大人の所作で食べる" という価値観そのものを店名にする。

タグライン: **「大人になってから、甘いものは夜に食べる。」**

TikTokでバズる理由は「派手な色」ではなく「所作」。
炙る、燻す、注ぐ ―― バーテンダーのようにデザートを仕上げる
"パフォーマンス"が動画のフックになる、という設計。

## 2. デザインプラン(トークンシステム)

### カラー ― 白ベース+燃える金1色(彩度を絞った“大人”パレット)

| トークン | HEX | 役割 |
|---|---|---|
| `--bg` | `#FFFFFF` | 基本背景。ユーザー指定の「白ベース」。ギャラリーのような
  静かな余白として、器や所作を主役にする |
| `--surface` | `#F7F4EF` | カード面。白から石灰石のようなごく淡い温灰色へ |
| `--ink` | `#15110C` | 本文色。純黒でなく、炭化した木のような温かい黒 |
| `--ink-soft` | `#6E655A` | 補助テキスト |
| `--ember` | `#B9862E` | 燃えるキャラメル・炎・琥珀色。ロゴ/CTA/火の粉のみに使用する
  唯一のアクセント。彩度を意図的に落とし「大人」の落ち着きを保つ |
| `--smoke` | `#C7C2B9` | 燻煙・グラデーションの中間色(装飾のみ、情報を持たない) |
| `--line` | `#E7E2D8` | 罫線 |

前2軒がビビッドな2色使い(ピンク×ティール/朱赤×焦げ茶)だったのに対し、
本案はアクセントを琥珀色1色だけに絞り、彩度も明度も抑えることで
「かっこよさ=引き算」という大人の文法を作る。

ダークモードは `--bg` を `#14100B`、`--surface` を `#1D1712` に反転。
既定はライト(白ベース)。

### タイポグラフィ

- **ロゴ/見出し**: 前2軒と同じ制約(Webフォント取得不可)のため
  system-ui 900ウェイトを使うが、字間を大きく "詰めて立たせる"
  のではなく、逆に若干広げに取り(letter-spacing: 0〜+0.01em)、
  バーの看板のような静かな威厳を出す。前2軒(詰め字・グラデ塗り)
  との差別化として、本案のロゴは単色(ink)を基本にし、
  唯一「夜」の一文字だけ`--ember`で灯す。
- **日本語見出し・本文**: `"Hiragino Sans","Yu Gothic UI","Noto Sans JP",sans-serif`。
  見出し900、本文700。ユーザー指定の「文字大きめ」に応じ本文19px、
  見出しclamp()で最大84px程度。行間を通常よりやや広く取り、
  静けさを演出する。
- **キャプション/価格**: 同スタック900 + `tabular-nums`。

### レイアウト

白い余白を「照明を絞ったバーカウンターの上に置かれた一枚の白い皿」に
見立てる。ヒーローは中央に大きくロゴを置き、その脇にCanvasで
「一本のマッチの炎」だけを揺らめかせる ―― ブロブや豹柄のような
面的な装飾ではなく、点(炎)ひとつに絞ることで「大人の引き算」を
体現する。メニューは実際のバーのドリンクリストのような横組みの
一覧形式を基調にし、写真の代わりに炎色のグラデーションを
小さく添えるだけに留める。

## 3. プランの検証(汎用パターンの排除)

- ❌ 初期案: 「大人かっこいい」を安易に「黒背景+金文字」の
  高級ラウンジ的な生成AI定型に寄せそうになった → ✅ 修正:
  ユーザー指定の白ベースを守りながら、色数を1色(琥珀)にまで
  絞り、面ではなく所作(炙る/燻す/注ぐ)を主役にすることで、
  黒背景に頼らず「大人」を成立させた。
- ❌ 初期案: 前2軒と同じ「カード型メニューグリッド+写真枠」の
  パターンをそのまま流用しそうになった → ✅ 修正: メニューを
  バーのドリンクリストのような横一列テキスト主体のリスト形式に
  変更し、ビジュアルよりも所作の説明(炙る、燻す、注ぐ)を読ませる
  構成にした。
- ❌ 初期案: ヒーローに前2軒と同じ「Canvasで面的な有機図形を
  揺らす」演出をそのまま流用しそうになった → ✅ 修正: 面ではなく
  「一本の炎」という点の演出に絞り、大人の静けさと点数の少なさで
  差別化した。

## 4. セクション構成(Claude Codeでの実装単位)

1. Hero ― ロゴ、タグライン、Canvasの灯り(マッチの炎)、CTA2種
2. Concept ― 「なぜ夜に、甘いものか」3原則(所作/静けさ/余韻)
3. Signature Menu ― バーリスト形式の5品(炙る/燻す/注ぐ/焦がす/灯す)
4. Buzz ― TikTok指標ストリップ+動画風タイルグリッド
5. Gallery ― 店内ビジュアル(CSS/SVGの抽象タイル、琥珀×炭の濃淡)
6. Access ― 住所・営業時間(架空設定として明記、夜営業を強調)
7. Footer ― ロゴ、ナビ、コピーライト

## 5. 実装メモ

- 完全自己完結の単一HTML。外部フォント/画像CDNは使用しない。
- 実在の写真・実在店舗のレビューを装った引用は使用しない(架空店舗)。
- 過去2軒での反省を踏まえ、バッジ類は必ず親要素の内側にネストし、
  モバイル最小幅(360〜390px)でのclamp()下限と横スクロール有無を
  実装直後に実機相当のビューポートで確認してから確定する。
