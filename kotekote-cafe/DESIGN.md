# KOTEKOTE CAFE ― 大阪発・Instagramで一番バズっているカフェ

## 1. コンセプト

大阪でいちばんInstagramがバズっている、という設定のカフェ。
安易な「おしゃれインスタ映えカフェ(パステル・観葉植物・白タイル)」には
絶対に寄せない。軸は大阪弁でいう **「コテコテ」**(=とことん濃い、
やりすぎなくらい大阪らしい、の意)。大阪のおばちゃん文化の象徴である
豹柄(ヒョウ柄)を下品に使うのではなく、グラフィックとして上品に
抽象化し、白い余白の中に効かせる ―― という「コテコテを洗練させる」が
デザイン全体のロジック。

コピーのトーンも大阪弁のツッコミ・オノマトペを効かせ、
「映えるでしょ、これ」を真顔で言い切る自信のある声にする。

店名「KOTEKOTE」はそのまま大阪弁の一般語彙。サブネームに
「喫茶 コテコテ」と和文表記を添え、純喫茶(大阪に根強い喫茶店文化)
とインスタ映えの両方を背負わせる。

タグライン: **「コテコテやけど、なんでか、映える。」**

## 2. デザインプラン(トークンシステム)

### カラー ― 白ベース+豹柄由来の1トーン

| トークン | HEX | 役割 |
|---|---|---|
| `--bg` | `#FFFFFF` | 基本背景。ユーザー指定の「白ベース」。豹柄を「柄」ではなく
  "白地に効かせる図形" として使うための余白 |
| `--surface` | `#FFF9F0` | カード面。白から極わずかに黄味(喫茶店のクリーム色)へ |
| `--ink` | `#241708` | 本文色。純黒でなく、コーヒー豆のような焦げ茶がかった黒 |
| `--ink-soft` | `#8A7A63` | 補助テキスト |
| `--accent` | `#FF5A1F` | 大阪のネオン看板・グリコサインを思わせる朱赤オレンジ。CTA/ロゴ/価格のみに使用 |
| `--spot` | `#3B2412` | 豹柄グラフィックのスポット色(アクセントより濃い焦げ茶) |
| `--line` | `#EFE6D6` | 罫線 |

アクセントは朱赤オレンジ1色のみ。豹柄は色ではなく「形」の要素として
`--spot`(焦げ茶)の不定形スポットをSVGパターンで生成し、ロゴ下線や
セクション区切りなど装飾ではなく“境界線の代わり”として機能させる。

ダークモードは `--bg` を `#1B130A`、`--surface` を `#241A0E` に反転。
既定はライト(白ベース)。

### タイポグラフィ

- **ロゴ/見出し英数字**: 実行環境からのWebフォント取得ができない制約は
  前回と同様のため、system-ui の極太(900)をベースに、日本語の看板文字
  ("たこ焼」「串カツ」の暖簾・置き看板のような、極太で詰まったゴシック)
  の質感を字間を詰めて再現する。ロゴタイプ「KOTEKOTE」はSVGで
  1文字ずつ僅かに傾き・大きさをずらし、量産フォントに見えない
  手描き看板っぽいリズムを作る。
- **日本語見出し・本文**: `"Hiragino Sans","Yu Gothic UI","Noto Sans JP",sans-serif`。
  見出しは900、本文は700を基本に、ユーザー指定の「文字大きめ」に応じ
  本文19px、見出しclamp()で最大88px程度まで。
- **キャプション/価格**: 同スタックの900 + `tabular-nums`。

### レイアウト

白い余白を"喫茶店の店内照明に照らされた白いテーブルクロス"に見立て、
その上に朱赤の見出しと焦げ茶の豹柄スポットだけを大胆に置く。
ヒーローはCanvasで豹柄スポットをアンビエントに揺らめかせ、
メニューは実在の純喫茶メニュー(プリン・ナポリタン・クリームソーダ)を
大阪のノリで再構築した5品を看板風カードで見せる。SNS投稿は実際の
画像がないため、色帯+キャプションのタイル状「投稿風グリッド」として
抽象化する。

## 3. プランの検証(汎用パターンの排除)

- ❌ 初期案: 「おしゃれ映えカフェ」としてパステルグリーン+観葉植物+
  丸ゴシックという、生成AIが最も出しがちな“カフェサイト”の定型に
  流れそうになった → ✅ 修正: 大阪という土地の実際の文化的記号
  (豹柄・コテコテ・純喫茶・ネオン看板)に振り切り、白ベースの中で
  唯一豹柄スポットだけを主張させることで「量産カフェ」から遠ざけた。
- ❌ 初期案: 角丸カード+絵文字見出しに寄りかかりそうになった →
  ✅ 修正: 角丸を弱め、メニューカードは「暖簾(のれん)」のように
  上端がギザギザに切れたSVG形状にし、絵文字の代わりに大阪弁の
  一言ツッコミキャプションで個性を出した。
- ❌ 初期案: グラデーションヒーローにしそうになった → ✅ 修正:
  グラデーションを廃し、白地+焦げ茶スポット+朱赤テキストのみの
  フラットで硬質な組み合わせに統一。

## 4. セクション構成(Claude Codeでの実装単位)

1. Hero ― ロゴ、タグライン、Canvas豹柄アンビエント、CTA2種
2. Concept ― 「コテコテってなんやねん」3原則
3. Signature Menu ― 純喫茶メニューを大阪流に再構築した5品(暖簾型カード)
4. Buzz ― Instagram指標ストリップ+投稿風タイルグリッド
5. Gallery ― 店内ビジュアル(CSS/SVGの抽象タイル)
6. Access ― 住所・営業時間(架空設定として明記)
7. Footer ― ロゴ、ナビ、コピーライト

## 5. 実装メモ

- 完全自己完結の単一HTML。外部フォント/画像CDNは使用しない。
- 実在の写真・実在店舗のレビューを装った引用は使用しない(架空店舗)。
- 前回(BAKEBAKE)の反省を踏まえ、バッジ類は必ず親要素の内側に
  ネストして配置し、paddingとposition:absoluteの相互作用による
  はみ出しを避ける。モバイル最小幅(360px)でのclamp()下限を
  必ず実機相当のビューポートで確認してから確定する。
